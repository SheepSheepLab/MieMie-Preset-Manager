# MieMie Preset Manager 0.6.0

咩咩预设管理 0.6.0 更新每聊天预设绑定，并修复生成与异步协调问题。

## 一个聊天记住一个预设

- 新聊天自动绑定创建时的默认预设。修改全局默认，不会改变已有聊天的有效绑定；聊天选择当前默认预设后，也保留独立绑定。
- SillyTavern 原生切换与 MPM 切换双向同步，原生已完成的相同预设切换不会重复应用。
- 单人和群聊重命名保留绑定；刷新、重新打开及重启后仍保持。新建、复制及同角色不同聊天分别初始化。
- 绑定预设确认删除后，聊天回退到当前默认并保存该结果。读取失败不会被当作删除。
- 绑定引用原生预设身份；用户仍可自由修改预设内容，不冻结内容、不创建隐藏副本。

## 发送与数据可靠性

修复斜杠命令后持续阻断发送、工具调用续接误取消、酒馆助手自动上下文调整冲突，以及新聊天首次发送、重复加载和异步读取取消的协调问题。未完成原生应用的等待期限不再被重复事件不断延长；失败有明确提示，状态恢复后可以重试。

继续使用原生 Preset，保留未知字段、完整导入导出和统一保存。聊天重命名不改写聊天正文或其他扩展 metadata。

## 从 0.5.1 升级

**0.5.1 的旧绑定关系不会迁移到新绑定系统。** 旧聊天首次进入 0.6.0 时，按新规则初始化绑定；如需使用其他预设，请为该聊天重新选择。升级不会主动删除原生预设、聊天正文或其他扩展数据。

通过 Tavern Helper 导入本 Release 的脚本 JSON，或通过兼容 MieMie Hub 的正式安装／更新功能获取。请保留可恢复备份，只启用一个预设管理实例。

## 已知限制

- Hub Esc 层级冲突仍存在；暂用界面上的返回、取消、关闭按钮，避免未确认草稿丢失。
- 社区“42 层后失效”：未能复现（NOT REPRODUCED）；特定角色卡正文隐藏：原因未确认（UNCONFIRMED）。不宣称本版解决了所有相关反馈。
- 真实供应商模型组合、物理手机及完整 Safari 矩阵未全部验证。
- 缺少可信原生重命名事件的外部文件移动会停止覆盖以保护 metadata；原生跨客户端存储不提供事务保证。
