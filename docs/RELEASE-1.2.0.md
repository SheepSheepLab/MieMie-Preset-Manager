# 咩咩预设管理 1.2.0

## 1. 新增【预设下载】

- 在「更多预设操作」里，可以浏览官方预设和正则，查看发布日期和更新日志。
- 下载预设时，可以选择同时下载配套正则并绑定到新预设。
- 下载正则时，可以选择「仅下载文件」或「绑定到预设」。已有正则时，新规则按原有顺序追加在末尾。仅下载文件时，浏览器负责保存 JSON。
- 下载时显示进度，并可取消。导入或绑定前会校验文件的大小与 SHA-256。

## 2. 【预设工具】按预设设置

- 「预设工具」和「预设参数设置」并排显示。每个预设独立记住工具开关及自定义提示词。
- 新增「低思考模式」。在当前模型支持的情况下使用已确认的最低推理档位，并关闭原生思维链回传。
- 新增「标签隔离」，减少正文以外的游离标签被正则误匹配。隔离标签可编辑。
- 普通预设默认只开启标签隔离。带有「📜说明」及 SheepSheep 署名的咩咩预设，还默认开启低思考模式、工具调用回复及三个对话状态引擎。咩咩预设缺少最大回复长度时使用 64000。

## 3. 对话状态引擎

- 「好感度引擎」支持识别预设中的方括号区块与分隔线。脚本根据本回合变动结算，并把完整名单写回回复。
- 「状态栏引擎」保留状态栏字段及规则，从最近的完整状态栏按标题更新变化。
- 新增「世界运行报告引擎」，从最近的完整报告按模块标题更新。状态栏和世界运行报告的增量提示词都可以编辑。

## 4. 条目编辑与分组

- 重排条目编辑中的高级设置。关闭的条目会变暗，开启条目时增加扫光反馈。
- 自动分组要求分类前缀以 Emoji 开头，例如 `🧷卡原生思维链-规则`。酒馆默认的 `Post-History Instructions` 归入「未分类」。

## 安装与兼容

- 在 Hub 的扩展中心安装或更新，或下载 `MieMie-Preset-Manager-Extension-1.2.0.json` 并导入酒馆助手的全局脚本。
- 延续 1.1.0 的 SillyTavern 1.14 至 1.19 适配范围。Hub 集成沿用 Runtime API2 和 Package v1。
- 本版预设下载直连官方 GitHub 仓库。香港下载服务代码已随源码提供，当前发行包使用 GitHub 下载入口。
