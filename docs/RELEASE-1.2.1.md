# 咩咩预设管理 1.2.1

- 修复酒馆助手开启「最大化预设上下文长度」时，预设管理可能误报原生预设有未保存修改的问题。
- 在受影响的配置下，打开面板和重新读取可继续使用当前预设。原生界面确实有未保存修改时，打开面板会恢复当前预设的已保存内容。

可在 Hub 的扩展中心更新，或将 `MieMie-Preset-Manager-Extension-1.2.1.json` 导入酒馆助手的全局脚本。

## 验证

- TauriTavern 2.4.0 官方 ARM64 安装包，Android 14 模拟器，宿主接口 1.19.0，酒馆助手 4.11.3。使用两份测试预设复现 1.2.0 的未保存提示及额外切换事件，确认 1.2.1 打开和重新读取都能读到当前预设，切换事件计数保持不变。
- 在 TT 原生界面临时修改温度。打开 1.2.1 后恢复为预设的已保存值，当前预设名称及预设文件内容保持一致。
- Hub Runtime 在安卓 TT 上实际打开 1.2.1 的窗口。用酒馆助手更新本地测试脚本后回读完整内容。冷重启后，Hub 同时识别出保存和运行的版本号为 1.2.1。
- Managed Package v1 的 78 项自动检查独立通过。发布前的本地测试更新通过酒馆助手完成。Android 验证使用模拟器。
