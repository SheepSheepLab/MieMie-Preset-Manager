# MieMie Preset Manager 0.2.1

0.2.1 adds MieMie GitHub Extension Package v1 compatibility. Compatible Hub versions can recognize this repository as a Managed GitHub Extension, install it, identify the installed product, check updates and update future conforming releases in place.

- Standard manifest shared with Runtime identity; launcher fallback remains “预设”, official PNG unchanged.
- Strict first-line Build Identity includes stable product/Script IDs and repository.
- Standard MieMie-Extension-update.json records the complete manifest, raw JSON size/hash and separate content hash. Downloads are resolved through GitHub Release API.
- Four reproducible release assets: Extension JSON, metadata, manifest.json and SHA256SUMS. GitHub Asset digest remains required independently.
- Pinned actual Hub validator/discovery/install/update contracts cover production output and reject malformed packages. Test fixtures are excluded from Runtime.

Preset data model, Dirty sessions, drag, Presentation, Standalone/Hub/Shortcut and licensing/brand boundaries are unchanged. No Per-Chat feature is included. Phase 1 remains incomplete; this is a Pre-release and Issue #1 remains Open.

Automatic contract validation does not mean real Hub online installation, browser CORS, durable Helper saving or updates have passed Owner acceptance. Existing Foundation real-host evidence retains its original version/environment scope; ST 1.19 and physical mobile remain pending.

0.2.1 is the first standard Managed Package. Manual 0.2.0 has no repository in its Build Identity and is not safely recognized by current Hub installed-identity logic. Back up the old script and important presets, disable and manually remove the old instance in Helper only after confirming recovery, then install 0.2.1 through Hub. Do not run duplicate instances; old script data is not automatically transferred. See README for migration scope. v0.2.0 Tag, Assets and Release Notes remain untouched.
