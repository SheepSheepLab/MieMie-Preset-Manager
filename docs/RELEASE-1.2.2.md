# 咩咩预设管理 1.2.2

- 修复开启「标签隔离」后，正文内的定位、平行线等标签无法美化的问题。是否隔离根据标签配对和所在位置判断，适用于有正文包裹标签和无包裹标签的回复。
- 默认隔离名单精简为 15 项。其他标签可在「预设工具 → 隔离标签」添加，随当前预设保存。
- 保留原有紫色配色，略微压暗面板底色、页眉和页脚。

可在 Hub 的扩展中心更新，或将 `MieMie-Preset-Manager-Extension-1.2.2.json` 导入酒馆助手的全局脚本。
